やり方は personal-aesthetic-cxelegy の `tools/replicate/METHOD.md`（Craft Anything の流れ）を参考にしている。

## Brief（何を合格とするか。作る前に決めた基準）
対象: `index.html`（3案を選ぶページ）, `a-bold.html`, `b-cool.html`, `c-simple.html`。幅 1400 / 390 / 320px。
必須項目（`node verify/check.js` が数字で判定）:
1. 横にはみ出さない（はみ出し 0px）
2. 写真を切らない・歪めない（表示の縦横比と元の縦横比の差 1% 以内、親要素で隠れていない）
3. 要素どうしが重ならない（1px 以上の重なり 0 件）
4. 表示後にレイアウトが動かない（CLS 0.01 以下）
5. 全部の画像が読み込める、スクリプトのエラーなし
6. 文字は 13px 以上
合格条件: 必須項目が2回連続で全部合格。

## 独立レビュー（1回目）で直したこと
- パソコンで拡大表示の「Close」が押せなかった（左右の矢印の領域が上にかぶっていた）→ 矢印の領域を縦60%にした。実際にクリックして閉じることを確認
- B案のスマホで contact に行くボタンがなかった → all / profile の下に contact を追加
- 灰色の小さい文字が読みにくい（B 3.4:1、C 2.8:1）→ #6b6b6b（5.3:1）に。A案のボタンは白文字 4.0:1 → 墨黒文字に
- 拡大表示のクレジット 11px・番号 12px → 13px
- A案・B案の列を「番号順に、いちばん短い列へ入れる」方式に変更（横に読んでも順番どおり。列の長さの差が小さくなった）。A案はパソコンで3列にして、縦長の写真が1画面に収まるようにした
- A案の流れる帯（同じ名前を4回・端で切れる・和文だけ細い）→ 動かない一覧に。メールアドレスと得意分野を表示
- A案の大きな見出しの行間（文字が触れていた）を広げた
- 「誌面を見る」のまま次の作品へ行くと誌面のままだった → 作品を変えたら写真表示に戻す

## 直していないこと（ユーザーの判断・素材待ち）
- 元の写真が小さいもの（glow 3点は横200〜235px、美的の一部）は拡大されてぼやける。大きい元画像が必要
- B案のホバー（写真の上に暗い幕＋媒体名）は参照ページの作りなので残している。「重ねない」に合わせるなら外す
- 題名のない作品が多い（59点）。題名・クレジットは本人に確認が必要
- 各案から比較ページへ戻るリンクはない（比較ページは公開前の確認用のため）
