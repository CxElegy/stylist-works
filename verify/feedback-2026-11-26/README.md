## 独立レビュー（結論を見ていない別の審査役。PC・スマホ・タブレット幅・スマホ横向きで実際に操作）
判定: 1 動きはそのまま＝満たす／2 横並びの一覧＝満たす／3 拡大表示＝満たす／4 文字色＝一部（淡い名前が写真の上に乗る）
直したこと:
- スマホのトップで、固定された名前とメニューが写真の上に乗り続ける → 下へ読み進めるあいだは消し、上へ戻して出すときは白い帯を敷く
- スマホの一覧で、× の白い丸が名前の行にかかる → 白い丸は一覧を送ったあとだけ
- 一覧を開いたまま再読み込みするとトップに戻り、「戻る」が2回必要 → 住所（…#beauty）でその一覧を直接開く。「進む」でも入り直せる
- スマホ横向きの拡大表示で、枚数の表示が写真に重なる → 写真の高さの上限を調整
- スマホで一覧が重い（13点で 2.5MB）→ 一覧は小さい画像（横720px）を使い、7点目からは近づいたら読む。拡大は小さい画像をすぐ出して元の画像に差し替える
- キーボードで一覧を送れない／名前の上ではホイールが効かない → どちらも送れるように
- 拡大表示の前後ボタンのフォーカスの線が画面の高さいっぱい → 矢印のまわりだけ
- 拡大表示の × と一覧の × が同じ位置で、続けて押すと両方閉じる／Esc を素早く2回でサイトの外へ出る → 拡大表示を閉じた直後の0.45秒は一覧を閉じない
- 一覧に入るとき、写真と一覧が0.4秒ほど二重に見える → 白くなってから一覧を出す
- 見開き（チェリーメイク）の端に隣のページが写り込んでいる → 写り込みと白いふちを切り落とした（誌面そのものは切っていない）
直していないこと:
- PC で写真に触れたときの大きな文字が写真にかかる（今までの動きなので変えていない）
- プロフィールがダミー文、連絡先が info@example.com（本人の情報待ち）
