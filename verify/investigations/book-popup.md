## 先说最重要的三件事
1. **这段视频其实是三段拼起来的**（图 01、05）：
   - 0–9.30 秒（f0–f278）：角标「原片 · 1.2W点赞」，海外原片，4 页家具。**每页之间是硬切**（f66、f137、f202），所以原片里**看不到一次完整的翻页**，只看到纸落下的后半截。
   - 9.30–19.57 秒（f279–f586）：角标「AI 复刻版」，是转发博主自己用 AI 重做的皮包版，**一个镜头到底，有 3 次完整翻页**。
   - 19.57–23.33 秒（f587–f699）：博主的片尾卡片，和效果无关。
   所以「翻页怎么翻」的数字**只能从博主的复刻版量到**；「实物怎么长」两段都有。
2. **整段是 AI 生成的写实视频**，不是网页、不是 3D 程序（证据 E20）。它的好看来自写实的材质、阳光和影子。
3. **用户最喜欢的那一点（实物从纸里变成真的），只有平面图片是做不出来的。** 平面图 + CSS 能留下的只是「一本摊开的书 + 翻页」。详见「可复现性」表。

## 第 0 步（共用）
- 用户原话（`AESTHETIC.md` 第 128 行）：「**这个相当好。做说明书时，它像一本书，打开书可以看到实物从书里变成真的**」。用户自己的描述：「阳光斜照的木桌上摊开一本产品画册，纸上印的平面家具或皮包，一页一个『长』成立体的微缩实物站在纸上；旁边是材质色卡、线稿和规格文字；画册自动翻页。」评分 3（最高）。
- 心动点（候选，等用户确认）：
  1. **翻到新的一页，纸上那张平平的产品图在原地鼓起来、站起来，变成一件有真实材质、拖着长影子的小实物。**（对应原话「实物从书里变成真的」。只有平面图做不出来。）
  2. **它是一本真的摊在木桌上的书：米白的纸、书脊拱起的弧度、斜照的暖阳光；纸自己慢慢掀起，然后很快落下。**（对应原话「它像一本书，打开书」。平面图 + CSS 能做到一部分。）
  3. 每一页都是同一套画册版式：主角在上，旁边是色卡、线稿、几行规格小字。（对杂志页不适用：杂志页本身已经是排好的版。）
- 找源头：搜了 2 次网页（英文描述「AI video open furniture catalog … flat printed sofa grows into 3D miniature … page turns」；页面上的原文「MODERN TWEED ACCENT CHAIR」「MODERN CANE & WOOD SIDEBOARD」），**没找到海外原片和作者**。没有搜 Instagram / TikTok / X 站内。没找到 ≠ 不存在。
- 选路线的理由：只有视频，没有可读的代码 → 路线 B，净室。

## Brief
- 要回答的问题：画面上有什么；每一种状态；逐帧时间；页内版式；心动点；哪些能用平面图 + CSS 做、哪些不能。
- 为什么：用户要把这个参考变成网站里「杂志作品」的看法——一本摊开的书，访客一页页翻。
- 目标：给建造者一份不看视频也能照做的规格。
- 模式：净室。
- 约束：只有她的平面杂志页图片（多数竖图约 0.78，少数跨页约 1.58）；没有 3D 模型、没有抠好的实物。
- 什么样算完成（研究部分）：规格里每条声明都有证据编号、测法、数字标准；做不到的效果明说。

一句话：**大约每 2.0–2.5 秒一页；翻页 0.7–1.0 秒（慢慢掀、很快落）；落平后约 0.1 秒开始长，长 0.5–0.9 秒；长成后静止 0.4–0.9 秒。**

## 可复现性（只有平面图片 + CSS / JS）
| 效果 | 能做吗 | 忠实的平面图版本能留下什么 |
|---|---|---|
| 一本摊开的书放在桌上，斜着看 | 能（CSS 3D） | 但原作的角度会把页面压扁、裁掉大半；我们要「整页看全」，只能用很小的倾斜或不倾斜 |
| 一张两面的纸绕书脊翻过去 | 能 | 正面 = 当前右页，背面 = 新左页 |
| 慢慢掀起、很快落下、不回弹，0.7–1.0 秒 | 能 | 用关键帧照时间表做 |
| 纸是弯的 | 部分 | CSS 不能把一张图弯成曲面；可以把纸切成 8–12 条竖条，每条多转一点，近似成弧形。要真的曲面需要 WebGL |
| 翻页时纸下面移动的影子、纸的明暗变化 | 部分 | 用跟着进度变的渐变层，是画出来的，不是真的光 |
| 运动模糊、纸透光 | 部分 | 可以整张纸轻微模糊 / 变亮；没有方向感，也不是真的透光 |
| 书脊处拱起的弧度、书页厚度 | 部分 | 渐变和几条细线做出样子；页面图片本身是平的 |
| 木桌、斜照的阳光、景深 | 部分 | 要自己拍或自己生成一张桌面图（不能用原作的），或者用素净的暖色底。用 CSS 画木纹容易显得假 |
| **平面图长成立体实物（鼓起、站起、投下影子）** | **不能** | 没有抠好的实物，也没有 3D。整张照片「抬起来加投影」是另一种效果（一张卡片浮起来），不是「实物变成真的」 |
| 实物缩回纸里、金属闪光 | 不能 | 同上，没有实物 |
| 实物旁边的色卡、线稿、规格文字 | 不适用 | 杂志页已经是排好的整页；再加色卡、线稿就是编造内容 |
| 主角只在左页、右页是配角 | 不适用 | 我们的左右两页都是作品，同样重要 |
| 自动翻页（约每 2.2 秒） | 能 | 但 2.2 秒看不完一页杂志，间隔要另定 |

**结论，直说**：只用平面图，这个参考里用户点名喜欢的那件事——「实物从书里变成真的」——**会完全丢掉**；一起丢掉的还有写实的材质、真实的阳光和长影子。剩下的是「一本摊在桌上的书，纸慢慢掀起、很快落下」。这是「受它启发的翻书」，不是「复刻了它」。原作的技术层级是 AI 写实视频，CSS 3D 低一级，按 METHOD 的 B6 要在动手前告诉用户分数会封顶。用户以前因为「卡通图层」顶替写实素材打过 1 分，所以这里**不要用假的立体效果去顶替**。
