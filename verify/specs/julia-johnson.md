# 规格：julia-johnson（给建造者；建造者不看原作代码）

来源：运行记录 `verify/investigations/julia-johnson.md`（证据 E1…，结论 C1…）。参考图：`verify/investigations/julia-johnson/01…10`（只用来对比，不能用进成品）。
写法：每条 = 声明（用我自己的话）｜来源证据｜怎么测｜通过标准（数字）｜档位（必须 / 应该 / 不做）。
记号：W = 视口宽，H = 视口高，格 = W ÷ 3。「来源」列标 **[静]** 的只有静态证据（从样式和结构读到，没看到它运行）；标 **[动]** 的是在录屏上量到的。
通过只代表写下来的这一条成立，不代表「和原作完全一样」。

## A10 验证结果（构建方）

成品：`r2-julia.html`（单文件）。测量脚本和原始数据在 scratchpad `build/julia/`（verify.js、results/verify.log）。对比图：`verify/investigations/julia-johnson/build/`（cmp-desktop-first、cmp-desktop-scrolled、cmp-mobile、build-desktop-states、build-mobile-states）。
环境：Playwright Chromium，1440×900 和 390×844（DSF 2、hasTouch、isMobile），另测 320×568。
时钟：标「假」= Playwright 假时钟（install → pauseAt → 只用 runFor 推进）；标「真」= 真实时间里在页面内逐帧取样（CSS 过渡 / 动画不受假时钟控制，所以开场、菜单、淡入用真时间）。
无法测 算不通过。通过只代表这一条成立。
