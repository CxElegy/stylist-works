# 规格：friends-of-the-new（给造的人看；净室）

- 这份规格只用自己的话写行为和数值，不含原作的类名、变量名、公式、代码结构。造的人**只读这份规格**，不看原作代码。
- 证据编号（E…）指 `verify/investigations/friends-of-the-new.md` 的证据表。
- 档位：**必须** / **应该** / **不做**。「通过」只代表这一条成立，不代表「和原作完全一样」。
- 来源标「静态」的条目 = 只从 CSS / HTML 读到，没看到它实际运行；标「运行时」= 录屏逐帧量到。
- 记号：W = 视口宽，H = 视口高。「格」= 一个正方形模块的边长。
- 测试宽度：手机 390×844（主要）、320、桌面 1440×900。

## 二、我们这一版的设计选择（约束；大部分留给造的人和用户定）

### 用户已经定的约束
| 编号 | 约束 | 和原作的关系 |
|---|---|---|
| D1 | **照片不能被 CSS 裁掉**（显示比例和原图比例差 ≤ 1%，不被父元素遮住） | **和 G11 冲突**，见下面「冲突」 |
| D2 | 不出现杂志名、品牌名 | 原作的「组名」是艺人名；我们的组名用内容分类（现有：ビューティー / カジュアル / エレガンス / ポートレート / キッズ / エディトリアル） |
| D3 | 第一屏必须看到她是谁：「伊藤 あかり｜スタイリスト」，并且有一个联系按钮 | 原作首页没有自我介绍、没有联系方式（都在子页）。这是我们加的。注意：T5–T7 会让大字在滚动时换掉，所以名字 + 职业 + 联系按钮要放在不会被换掉的地方（例如顶部导航那一行），或者规定页面最顶时大字就是她的名字 |
| D4 | 文字是日文 | 原作大字是拉丁字母。日文明朝体的字宽是方块，T2 的「一行排满」要按字数重新定字号；行高 0.72 对日文可能会让字碰到上下的东西，要实测「不重叠」 |
| D5 | 手机优先 | 原作手机版的证据最全（运行时），以第一部分的手机条目为主 |
| D6 | 结果不能和原作一模一样；不用原作的照片、代码、字体文件、字标 | 至少改：字体、照片、文字、组名；颜色和点阵可以留也可以变 |
| D7 | 本仓库已有的检查（`node verify/check.js`）：不横向溢出；照片不裁不变形；元素不重叠（≥ 1px 的重叠 0 处）；CLS ≤ 0.01；文字 ≥ 13px | **和 N1 冲突**（原作 10–12px）→ 按 13px 以上做。**和 T1 / T4 有张力**：原作的核心就是大字盖在照片上，「元素不重叠」这条要给贴底大字开一个明确的例外，或者改成大字贴底但照片在它上方停住——**需要用户决定** |

### 冲突：原作裁照片，我们不裁（需要用户选）
| 做法 | 怎么做 | 得到什么 | 失去什么 |
|---|---|---|---|
| 甲：宽度贴格、高度按原图 | 照片宽度取整格数（手机 3 格或 4 格），高度按原图比例自然撑开；行高不再固定 | 一点不裁；左右边仍贴格线；大小交替还在 | 照片的下边不落在格线上，圆点和照片下边对不齐；行高不整齐 |
| 乙：框贴格、照片完整放进框 | 框还是整格（3×3 / 4×4 / 3×4），照片缩小到完整放进框里，靠右上 | 四条边的「位置」都在格线上，节奏和原作最像 | 照片比框小，框里会露出底色的边；照片显得小 |
| 丙：按原图比例选最接近的框，只接受差 ≤ 1% 的 | 多准备几种整格比例（1:1、3:4、4:3、2:3、3:2…），每张照片选最接近的；差超过 1% 的用甲 | 一部分照片四边贴格 | 大部分真实照片比例对不上整格，最后多数还是走甲 |
调查员的看法（推测，不是证据）：甲最稳，和「心动点 ③」的损失最小（右边、上边、宽度都还在格线上）。

### 字体（不能用原作的字体文件）
| 用途 | 原作 | 可以免费用的近似 | 说明 |

### 留给造的人定的
- 大字换名字（T5–T7）在桌面要不要也做：原作桌面没有证据，自己定。
- 点照片以后怎么看大图（原作是进子页；仓库现有版本是浮层）。
- 开场要不要（I1）。访客大多是手机，开场会推迟看到照片的时间。
- 悬停变彩色（G10）：造型师的作品颜色很重要，平时黑白可能不合适——**建议问用户**。
