# 规格：menu-point-swap（指哪变哪的菜单联动）（第 1 版，给建造者，净室）

用户确认：<待确认>。确认之后的改动在最下面的版本记录里各写一行。

- 来源：`verify/investigations/menu-point-swap.md`（证据 E1–E27，假设 H1–H5）。建造者**只读本文件**，不看原视频。
- 原作是一段 24.4 秒的剪辑视频（两个例子：A 饮品，B 可颂），不是能操作的界面。本文件只用自己的话写行为和数值；不要使用原作的照片、店名、字体。
- 用词：「列表」= 一列名字（我们是 6 个类型名）；「主图」= 跟着换的那张大图；「名字」= 主图旁显示的大字；「指到第 N 项」= 原作里手指停在第 N 行下面，我们版本里的具体操作见第二部分 P4、P5。`VW` / `VH` = 视口宽 / 高。
- 原作的时间是 30 fps 逐帧量的，误差 ±33 ms。
- 范围内：列表 + 主图 + 名字这一块的行为。范围外：选定类型之后进入哪个页面、整页的其他部分。
- 档位：必须 / 应该 / 不做。结果列由建造者验证时填（通过 / 不通过 / 无法测 = 不通过）。「通过」只代表这条声明成立，不代表和原作完全一样。
- 完成 = 所有「必须」项连续两轮检查都通过，并且用户接受剩下的差距。

心动点（候选，等用户确认；对应必须项 B1、B2、B3、C1）：
1. 手指停在哪一行，那件东西就在同一刻整件换成那一行的，名字也在同一刻出现在固定位置。
2. 手指滑动途中画面一直跟着换，一停就定住。
