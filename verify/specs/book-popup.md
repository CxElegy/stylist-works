# 规格：book-popup（给建造者；建造者不看原视频）

用户确认：还没有（等运行记录里「要问用户的」4 个问题的回答）。
来源：运行记录 `verify/investigations/book-popup.md`（证据 E1…）。参考图：`verify/investigations/book-popup/01…10`（只用来对比，**不能用进成品**）。
写法：每条 = 声明（我自己的话）｜来源证据｜怎么测｜通过标准（数字）｜档位（必须 / 应该 / 不做）。
记号：「翻页进度」0 = 纸还平放在右边，1 = 纸完全落平在左边。「纸」= 正在翻的那一张。计时用假时钟（Playwright `clock.install` 后 `pauseAt`，只用 `runFor` 推进）。
通过只代表写下来的这一条成立，不代表「和原作一样」。

**先读这一段**：原作是 AI 生成的写实视频。用户喜欢的核心是「实物从书里变成真的」（平面产品图鼓起、站起、投下影子）。我们只有平面的杂志页图片，这一点**做不出来，也不要假装做**（见第一部分 E 组和第三部分）。这份规格描述的是能留下的那一半：一本摊开的书和翻页。

## 三、会丢掉什么（请建造者和用户都知道）
- **丢掉**：平面图长成立体实物（用户原话里的「实物从书里变成真的」）、实物的写实材质、真实的斜照阳光和长影子、缩回纸里、金属闪光、实物旁的色卡和线稿、真的纸张曲面、景深。
- **留下**：一本摊在暖色桌面上的米白色的书；一张两面的纸慢慢掀起、很快落下、不回弹；翻页时移动的软影子；两次翻页之间完全静止。
- 原作是 AI 写实视频，这一版是 CSS 3D，技术层级低一级；按 `METHOD.md` B6，动手前要告诉用户分数会封顶。这一版应当叫「受它启发的翻书」，不叫「复刻」。

## 四、还没定、要用户回答的（详见运行记录）
1. 只有翻页、没有「长出实物」，还要不要这个版本。
2. 要不要另外准备写实素材来做「长出来」。
3. 自动翻页要不要，停几秒（现在按 Y9：默认不自动）。
4. 书正着放可以吗（现在按 Y2）。
