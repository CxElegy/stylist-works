# 规格：anchor-wordmark（字标不动、载体在变）（第 1 版，给建造者，净室）

用户确认：<待确认>。确认之后的改动在最下面的版本记录里各写一行。

- 来源：`verify/investigations/anchor-wordmark.md`（证据 E1–E15，假设 H1–H5）。建造者**只读本文件**，不看原视频。
- 原作是一段 6.2 秒的竖屏视频（720×1408）：一个字标停在原地，背后 25 张静止画面硬切，放两遍，第二遍逐渐放慢。本文件只用自己的话写行为和数值；不要使用原作的图片、字标、字体。
- 用词：「名字」= 不动的那个字标（我们是她的名字）；「底图」= 名字背后整屏换的画面；「一张」= 一次停留。`VW` / `VH` = 视口宽 / 高。
- 原作的时间是 30 fps 逐帧量的，误差 ±33 ms。
- 范围内：名字 + 底图这一块（开场或页头）。范围外：页面其他部分、点进去之后的内容。
- 档位：必须 / 应该 / 不做。结果列由建造者验证时填（通过 / 不通过 / 无法测 = 不通过）。
- 完成 = 所有「必须」项连续两轮检查都通过，并且用户接受剩下的差距。

心动点（候选，等用户确认；对应必须项 W1、W2、W3、W4）：
1. 名字一个像素都不动、大小不变，背后的画面一帧就换掉一张。
2. 名字像印在每样东西上，其实它没动；只有两种颜色，名字的颜色跟着底色翻转。

## 第二部分：我们版本的限制（设计选择，不是原作的行为）

| 编号 | 档位 | 声明 | 怎么测 | 通过标准 | 结果 |
|---|---|---|---|---|---|
| P1 | 必须 | 底图全部是她自己的作品 | 核对每张底图的来源都在本仓库的作品数据里 | 全部命中 | |
| P2 | 必须 | 这一块渲染出来的文字（包括 alt）里不出现杂志名和品牌名；底图本身也不选带明显杂志刊头或品牌标志的 | 取全部可见文字和 alt，和作品数据里的杂志 / 品牌字段比对；人工看一遍底图 | 文字命中数 = 0；带刊头或标志的底图 = 0 | |
| P3 | 必须 | 名字用日文和 / 或英文（Akari Ito、伊藤 あかり），不出现别的语言 | 检查文字 | 其他语言的字符数 = 0 | |

## 还没法写成声明的（未知，来自运行记录）
