# 12番台：どの版が何を組み合わせたものか

使える部品（すべて調査済み。規格は verify/specs/）:
| 記号 | 出どころ | 取り出す部品 |
|---|---|---|
| G | gregor-collienne | 名前が画面の真ん中に固定、写真の互い違いの壁が終わりなく流れる |
| J | julia-johnson | ひとりでに斜めに流れる写真の壁、隅の巨大な名前、写真の色の面→写真 |
| F | friends-of-the-new | 点の方眼紙、画面の下に固定された大きな明朝の一行（ジャンル名に切り替わる）、白黒→触れるとカラー |
| S | snog | 白い1画面に大小の写真が散らばる、中央から飛び出す、触れると拡大＋大きな文字、押すと中央に集まる |
| M | menu-point-swap | ジャンル名を指す（スマホはなぞる・押す）と、その瞬間に主役の写真と名前が丸ごと切り替わる（1コマで切り替え） |
| W | anchor-wordmark | 名前は1ピクセルも動かず、後ろの写真だけが次々に切り替わる（だんだんゆっくりになる） |
| B | book-popup | 誌面を「本」としてめくる（調査中） |

| 版 | 組み合わせ | 文字色 |
|---|---|---|
| 12A | W で始まり → S の散らばった画面へ飛び出す | 砂 |
| 12B | S の画面 ＋ M（ジャンル名の列を指すと、対応する写真が拡大して前に出る） | 赤土 |
| 12C | G の壁 ＋ M（「＋」の中のジャンル名を指すと、壁がそのジャンルの写真だけになる） | 夕空 |
| 12D | W で始まり → G の壁（固定された名前はそのまま、後ろが壁に変わる） | 砂 |
| 12E | J の流れる壁と巨大な名前 ＋ M（ジャンル名を指すと、壁がそのジャンルに切り替わる） | 赤土 |
| 12F | F の方眼紙と下の一行 ＋ W（一行は動かず、紙の上の写真が切り替わっていく） | 夕空 |
| 12G | M が主役（左にジャンル名、右に主役の写真）＋ F の下に固定された大きな一行 | 砂 |
| 12H | J の巨大な名前 ＋ S の飛び出す・集まる動き | 夕空 |
| 12I | G か F のトップ ＋ B（誌面は本としてめくる）※ B の調査が終わってから | 赤土 |

文字色（大きな文字 tint／小さな文字と線 ink）: 砂 #a39166／#786850、夕空 #8096a6／#586a78、赤土 #c4826c／#94584a。地は白（F を使う版は原サイトどおり紙色 rgb(244,244,239)）。

全部の版に入れるもの・決めごと・検証のしかたは 12-common.md。
